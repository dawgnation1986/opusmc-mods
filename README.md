# opusmc-mods

OpusMC 网页版 MC 辅助脚本发布源（Tampermonkey 自动更新用）。

## 安装（浏览器直接打开 .user.js 链接会弹安装）

- 主脚本（ESP/雷达/罗盘/夜视/ClickGUI）：https://raw.githubusercontent.com/dawgnation1986/opusmc-mods/main/opusmc-hud.user.js
- MC 1.8 直连内核（连 PHPMC 用）：https://raw.githubusercontent.com/dawgnation1986/opusmc-mods/main/opus-mc18-link.user.js
- 资源还原工具（导出贴图/数据表）：https://raw.githubusercontent.com/dawgnation1986/opusmc-mods/main/opus-resource-dump.user.js

装过之后 Tampermonkey 会自动检查更新（脚本头部带 @updateURL/@downloadURL）。
